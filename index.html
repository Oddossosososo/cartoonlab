THE BEGINNING OF TIME · UPDATE NOTES

CARTOONLAB · FEATURE CAMPAIGN

The Beginning of Time

A new creative workspace for building characters and worlds from editable 3D meshes.

Mini Mesh Lab

The Characters side panel now includes a mesh maker. Create cubes, spheres, cylinders, cones, pyramids and toruses, then customise each mesh's name, colour, position, size and rotation. Meshes render in the scene preview and can be used as props alongside your characters.

HSL project format rework

HSL exports now use format version 3. The full project payload stores mesh vertices, faces, object transforms, colours, characters, scenes and voice settings. Importing an older HSL project remains supported, while version 3 preserves the new mesh objects.

Campaign countdown

The five-minute campaign timer counts down to the update reveal. When it reaches zero, the campaign status changes to UPDATE READY. The timer is persisted in this browser so refreshing the page does not restart it.

What comes next

  • More mesh primitives and custom vertex editing
  • Drag-to-position and numeric transform tools
  • Mesh grouping, parenting and reusable presets
  • Improved material controls and lighting

Mesh editing is a lightweight primitive modeller in CartoonLab, not a replacement for the full Blender application.
